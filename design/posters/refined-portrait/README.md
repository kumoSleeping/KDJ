## 方法与变化

继续使用手工 SVG/CSS 合成，没有新增 AI 生成内容。原始上色来自此前本机 Krita 手绘底稿，来源 ../directional-light/assets/chihaya-directional-light.png；本轮改动不包含在旧 KRA 中。

去掉上一版跨过手腕、袖口、衣服的宽大阴影，修整额头发际填色与部分衣褶边线。保持深蓝瞳色，重绘虹膜明暗、瞳孔与有限的反光点，增加轻微脸颊暖色和微笑。裙摆以独立曲线面板重绘，褶线随右向摆动弯曲，保持腿部遮挡与裙长。

PSD 图层为栅格图层；文字和路径的精确编辑使用 HTML/CSS/SVG 源文件。本轮未通过原生 Photoshop 打开验证。旧版本均保留。
