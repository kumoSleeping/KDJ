# KDJ · 墨线光影海报

2:3 竖版，高清画布 2400 × 3600。米白纸色、黑色轮廓、蓝色硬边光影、珊瑚色领结。

## 交付

- exports/KDJ-ink-light-2400x3600.png：高清成图。
- exports/KDJ-ink-light-preview.png：1200 × 1800 预览。
- exports/KDJ-ink-light-layered.psd：10 个可独立开关的海报栅格图层。
- character/chihaya-ink-light.kra：Krita 角色分层源文件，包含底色、蓝色眼瞳、恢复的完整墨线、手工补线、局部硬边光影和独立整体暗面。旧高光层隐藏保留。
- assets/chihaya-ink-light.png：从 Krita 原生保存结果直接导出的透明角色。
- poster.html / poster.css / poster.js：可编辑文字、SVG 字形、纸面图形、颜色及布局的源文件；打开 HTML 可逐层预览。
- exports/layers/ 和 exports/layer-index.json：独立图层图片与图层索引。

PSD 中的文字与图形为栅格图层；编辑文字、字形及布局请使用 HTML/CSS/SVG 源文件。export-poster.cjs 可在本机重新输出。

## 此次修订

在本机 Krita 通过 Computer Use 操作完成全部角色修订：提取原线稿黑线置于颜色上方，手工连接发际、耳侧、手指与裙褶轮廓；修补刘海间、耳侧、握领手指、指缝和袖口；清除手腕与衣服间的白底。保留深蓝色瞳孔。

关闭原雾状高光，手工绘制顺着发束的明暗面、刘海投影、脸侧和下颌阴影、衣服与领结折面、百褶裙凹面和亮面。整体下半部暗面以独立正片叠底图层（27%）叠加，并继承人物透明度；胸口、袖子与发束的交界随体积轻微转折。

海报保留统一文字层级及手工 KDJ 字形，取消人物底部淡出遮罩和前景渐隐层，完整展示裙摆；GitHub 链接独立排到右侧，下方功能文案拆成两行。仅角色原始线稿使用 AI，所有角色上色和修订均通过本机绘画软件完成；排版及图形使用 HTML/CSS/SVG 设计。本版文件独立存放，上一版 hand-painted 交付文件保留。
