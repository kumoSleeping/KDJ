# KDJ · 手绘海报修订版

2:3 竖版，高清画布 2400 × 3600。米白纸色、克制的蓝色光影、珊瑚色领结。

## 交付

- exports/KDJ-hand-painted-2400x3600.png：高清成图。
- exports/KDJ-hand-painted-preview.png：1200 × 1800 预览。
- exports/KDJ-hand-painted-layered.psd：11 个可独立开关的栅格图层。
- character/chihaya-final.kra：Krita 角色分层源文件；保留底色、柔光、细线、双眼等图层以及隐藏的旧版参考层。
- assets/chihaya-porcelain.png：从 Krita 原生保存结果导出的透明角色。
- poster.html / poster.css / poster.js：可编辑文字、SVG 字形、纸面图形、颜色及布局的源文件；打开 HTML 可逐层预览。
- exports/layers/ 和 exports/layer-index.json：独立图层图片与图层索引。

PSD 中的文字与图形为栅格图层；编辑文字、字形及布局请使用 HTML/CSS/SVG 源文件。export-poster.cjs 可在本机重新输出。

## 此次修订

在本机 Krita 通过 Computer Use 完成分区补色、眼部重绘、细线修整与高光收敛。肤色统一为浅暖白；修补发根、颈侧后发、领片、腰带和袖口；深蓝虹膜配少量明确反光；旧的硬边头发亮面保留为隐藏图层。

海报统一文字层级，移除零碎顶部装饰，重新手工设计 KDJ 字形、纸面底色、蓝色画笔边缘和竖排标题。仅角色原始线稿使用 AI，所有角色上色和修订均通过本机绘画软件完成；排版及图形使用 HTML/CSS/SVG 设计。
