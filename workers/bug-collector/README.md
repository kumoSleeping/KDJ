# KDJ 错误收集

生产入口：<https://bug.kdj.kumo.ltd>。Workers 接收用户主动提交的报告，D1 保存报告；首页是管理员查看面板，报告列表、详情和删除接口均要求管理员密钥。

## 用户侧

设置 → 日志：打开本机日志文件夹，或选择「将错误上报至开发者」。先生成并核对完整脱敏预览，勾选本次同意，再点击确认上传。预览保留 15 分钟，发送的是同一份冻结内容，不会在上传时偷偷追加新日志。不会自动上传、自动重试，也不会记住下次同意；网络失败可手动重试同一报告，服务端按随机报告 ID 去重。

本地 `errors.jsonl` 与 `errors.previous.jsonl` 每份最多 4 MiB，`last-panic.jsonl` 同步保留最近一次 Rust panic，内存保留最近 300 条。单条详情最多 8000 字符，报告最多 256 KiB；超过上限时舍弃较早条目并注明数量。前端短时间重复错误会合并，溢出/写盘失败计数进入报告。原始 `kdj.log` 不会上传。

覆盖：前端全局异常、React 错误边界、console 警告/错误、Tauri 调用失败、媒体错误/共享视频跳转超时、官方嵌入播放器错误、本地 API 非成功响应、平台搜索/下载终态、Rust tracing 警告/错误与 panic、混剪/合成/可视化导出、硬件编码探测和失败回退、Canvas/WebGL 上下文丢失。

这不是系统级崩溃转储器：无法保证捕获断电、内核故障、进程强杀、内存耗尽、WebView 原生进程崩溃或硬件损坏。浏览器并不总暴露硬件加速原因；报告中的线程数、编码器和上下文状态不等于完整 CPU/GPU 硬件检测结果。未复现过的平台/设备路径仍需实际使用验证。

## 隐私与保留

只发送报告预览中的错误和运行环境字段。不扫描或附加曲库、媒体、截图、账号数据库、设置、环境变量、请求头、请求体。对常见凭证、用户路径、URL、邮箱、IP、手机号和长标识做自动脱敏，服务端再脱敏一次。自由文本无法保证识别所有姓名和私人内容，上传前必须人工核对；有私人内容时不要提交。

应用不会在打开面板、生成预览或正常运行时访问收集器。只有手动上传会建立公网连接。Cloudflare 作为网络处理方必然接触来源 IP；应用数据库不保存 IP、User-Agent 或身份标识。来源 IP 仅用于边缘临时限流。Worker 不记录报告正文、凭证或异常详情。

报告接收满 30 天后不再可查询，每日定时清理；Cloudflare D1 的平台恢复备份仍受 Cloudflare 自身的保留机制约束。单 IP 每分钟 5 次（共享出口可能受影响），单节点全局每分钟 100 次；数据库硬上限 1000 份报告、滚动 24 小时 100 份新报告。达到限额返回 429，不自动重试。边缘限流不是精确全球计数。

## 管理与部署

```sh
cd workers/bug-collector
npm ci --ignore-scripts
npm run check
npx wrangler d1 migrations apply kdj-bug-reports --remote
npm run deploy
npx wrangler secret put ADMIN_TOKEN
```

`ADMIN_TOKEN` 是独立的随机管理密钥，不是 Cloudflare API Token，绝不放进应用或仓库。首次部署时本机保存于 `~/.config/kdj-bug-collector/admin-token`（目录 0700，文件 0600）。在面板登录框输入该密钥；页面只在内存持有它，不写浏览器存储。退出或关闭页面即清除；清空剪贴板中的副本。轮换时更新 Wrangler secret 和本机私密副本。

面板支持按分类筛选、分页查看、下载和删除。公共上报接口没有客户端秘密；它依靠严格字段校验、大小限制、限流和存储配额防止滥用，不能将客户端内置秘密当作可信身份。

`wrangler.jsonc` 指定独立 Worker、D1、自定义域名和每日清理任务；不会修改 KDJ 更新服务。自定义域名首次启用需等待 Cloudflare 证书就绪。`workers.dev` 和版本预览网址均禁用。
