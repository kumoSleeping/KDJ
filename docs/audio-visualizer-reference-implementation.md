## 2. 按参考图实现的画面

默认画布为 1920×840、30 fps。左侧是倒置柔化图片及歌曲信息；右侧清晰图片用大弧形遮罩裁切。弧线、图片分界和频谱使用同一几何，避免律动时分界脱节。

弧线包含白色与青色双向频谱、细亮边、虚线轨道和青绿圆点。左上唱片支持隐藏、单圆盘旋转、方形封面遮挡旋转唱片；转速、转向、位置、尺寸与图片来源可调。方形封面为透明 PNG 补上不透明浅色衬底，实际遮住后方唱片，而非仅把透明立绘叠上去。

左信息区包含专辑、歌曲名、Remix/副标题、艺人、联名文字及补充信息；长文字按可用宽度缩放。系统字体用于中英文显示，没有复制原作者的专用商标或提供字体文件。

左下小频谱有白柱、青色平滑轮廓和透明能量历史线，支持柱状、曲线、混合和关闭。该层不绘制黑色山形填充，不使用黑底遮罩或乘法压暗图片，保留背后图像颜色。左侧图片整体淡化是独立可调项，与频谱背景无关。

左右图片、唱片、信息区和弧线分别响应低频能量、响度及起音；配置阻尼响应与不同运动相位。柔光和星点可以分别调弱或关闭。运动取决于歌曲时间和预计算特征，不依赖运行到这一帧之前发生了什么。

## 3. 操作面板

图片必须至少一张，最多两张；优先自动读取歌曲封面。没有可用封面时提示补图，不导出空画面。图片支持 PNG、JPEG、WebP、BMP，每张最多 16 MiB、解码后最多 3200 万像素。

一张图片可供左右栏和唱片共用；增加第二张后可分别选择来源。左右各自支持拖动焦点、缩放、旋转、镜像、柔化及复位。适配方式提供自动、填满裁切、完整显示；右栏自动模式遇到窄幅立绘优先完整展示，减少人物头部被默认裁掉的问题。

编辑器提供时间轴、播放/暂停、静音、拖动定位、撤销/重做、工程自动保存与恢复、工程文件导入/导出、样式预设。图片 Blob 存储在 IndexedDB，不把大图塞进 localStorage。导入工程保留当前选中的歌曲身份，不执行工程文件夹带的外部路径或切换音频源。

歌词默认关闭。可读取已有本地歌词或导入/粘贴 LRC，支持底部双语、滚动、唱片环形样式、字号及时间偏移。处理多时间标签、小数时间、offset、同时间双语及空白清句。没有逐字时间戳时只做整句切换，不伪造逐字对齐。

画布选项包括 1920×840、1920×1080、1280×720、2560×1080；视频输出可选 30/60 fps。初版支持最长 30 分钟的完整本地音频。流媒体占位、在线试听 URL 和缺失的源文件不能直接当完整歌曲导出。

## 4. 预览、导出和资源收敛

预览与离线导出调用同一个 Canvas 绘图实现。导出锁定工程快照，并按「帧号 / 输出帧率」绘制；不是录屏，不要求歌曲实时播放，也不在磁盘写逐帧 PNG。

本地受认证的 API 与原生 FFmpeg 配合输出 H.264 / yuv420p + AAC 的 MP4。后端按需索取带代次和序号的 RGBA 帧，有界背压，不缓存整首歌曲的所有图像。频谱白条和青条按颜色批量绘制，减少逐条阴影处理成本。

硬编候选、软件编码和整段重放沿用原生编码设施。编码重试产生新帧代次时，前端丢弃明确已过期的旧帧，不盲目重发失败 POST。自动模式不等于一定使用硬件；以本次实际编码状态为准。

导出前后校验源文件签名；成品检查时长、尺寸、音视频编码后，原子提交且不覆盖已有目标。取消与提交共享临界区，避免已提交成品被误报为取消。一般编码失败和用户取消分开报告；结束或异常均唤醒帧等待并清理临时文件。

单帧超过 40 秒未收到编辑器画面则终止。另有约 45 秒无控制请求的编辑器失联检查，覆盖尚在等待编码资源的任务。关闭面板需确认取消；意外退出还有后端检查。因此初版导出时应保持窗口打开，不承诺关闭 KDJ 后后台继续导出。

## 6. 使用方法

从本目录重新启动源码版 KDJ，前端和本地 Rust 服务需要一并更新；只刷新网页而保留旧服务不会得到新增导出 API。常规开发入口为 `npm run tauri:dev`，不需要发布新版本。

在本地曲库选一首歌，右键「生成可视化视频」。有封面时会自动带入；没有则添加一张图片。在右栏图片设置中调整人物焦点，竖幅立绘优先使用自动或完整显示。试听前手动暂停主播放器，避免两路声音叠加；当前面板不会擅自中断主播放器。

确认歌词是否要烧录、画布、帧率、输出文件夹和文件名，再点击「生成 MP4 视频」。文件名重复时明确报错，不覆盖旧视频。完成后使用「在文件夹中显示」。
