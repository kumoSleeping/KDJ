# RC6：abort 策略与针对性安全检查

## 策略决定

用户在了解取舍后明确要求发行版改回 `panic=abort`。RC6 保留前一轮的混合优化等级
（通用代码 `z`，音频/DSP 等级 2）、静态 Tauri ACL 和 DMG 无损重压，不提高原体积门禁。

**正常 `Result::Err` 仍走播放失败/重试流程；panic 会退出整个进程。**
`catch_unwind` 仅在 unwind 构建中有效，测试配置默认也是 unwind，不能用单元测试能
捕获 panic 来声称 abort 发行版可以恢复。代码注释、策略测试及 CI 测试选择已对应调整。
前一份 [体积报告](rc5-release-size-audit.md) 中的 unwind A/B 数值只作历史比较，
最终 RC6 包体以各平台发布构建为准。

## 这轮修复与加固

### 1. 分析解码缓冲区增长触发断言

`kdj-analysis/src/decode.rs` 原来仅按首包容量创建 `SampleBuffer`，后续大包/多声道包
直接复用会触发 Symphonia 的容量断言。现在在转换前检查实际总样本数，必要时扩容，
拒绝零声道、整数溢出及超过 16 MiB 的单包转换缓冲区。此上限不是歌曲时长/文件大小限制。
添加小包→大包→多声道→小包的精确样本回归测试，不通过吞掉 panic 掩盖问题。

同时拒绝非有限/负的分析起点和截取时长，样本累计与截取计算使用饱和运算；
PCM 扩容改用 `try_reserve` 返回错误。播放和 STEM 转换入口也显式拒绝零声道，
不再把它伪装成单声道后交给会除以原声道数的库；转换缓冲区缺失返回错误而非 `expect`。

### 2. 缩略图/二维码解码资源限制

新增 `kdj-providers/src/images.rs`，封面缩略图、二维码放大与抽帧明暗检查统一采用
显式 `ImageReader` 限制：边长不超过 8192、解码分配预算 64 MiB。之前方便函数采用
更宽泛的默认限制，没有针对缩略图用途设定尺寸上限。

支持的图片格式没有减少；超限图片沿原有失败分支处理，不继续分配全尺寸解码缓冲区。
混音编辑器的大幅图片仍使用其独立的已有策略。这不是全局 OOM 防护，也不约束
第三方解码器内部所有临时分配。新增普通 PNG 像素一致、伪造超大 BMP 头及无效数据测试。

### 3. CLI 本地控制客户端

HTTP 客户端构造由 `expect` 改为 `Result`；健康检查和窗口交接失败不引发 panic。
回环地址禁用系统代理，避免本地控制 bearer 被误送到 HTTP 代理；控制 API 不跟随
重定向。显式远程 `--url` 的原有代理配置不受回环例外影响。
新增错误地址及本机 HTTP 302 不跟随的回归测试，不访问真实账号或正常数据目录。

### 4. 正常错误恢复与安全边界复核

解码 worker 新增“首帧之前/之后返回 Err，随后仍可播放下一条流”的测试。
开发构建 panic 测试保留并明确标注 `cfg(panic="unwind")`。
复核了控制 bearer / 媒体 capability 权限分离、精确 Origin、短链/媒体重定向公网地址
约束、跨域凭证清除、曲库路径与符号链接边界、扫描取消/事务回滚，沿用已有防线，
未放宽 CSP、权限、网络白名单或签名校验。

## 本地验证

共 93 项相关 Rust 测试通过：analysis decode 13、图片 5、播放失败恢复 2、
HTTP 权限 6、CLI HTTP 2、provider 网络策略 12、目录边界 32、扫描 16、
播放器解码 2、STEM 音频 3。另有 `scripts/test-playback-recovery.mjs` 11 项通过。
测试使用内存、临时文件或本机临时端口，没有向真实账号发出写操作。
没有重复运行全工作区构建/跨平台检查；最终产物与其大小交给发布 CI。

## 剩余风险与发布边界

- CPAL 0.18.1 的 Windows WASAPI 源码仍有 `CreateEvent`、设备查询、性能计时等
  `expect` 路径；底层资源/设备异常可能导致 abort。没有把本轮输入检查冒充对这些
  上游问题的修复，也没有未经 Windows 验证就替换整套音频后端。
- 任意第三方解码器 bug、内存不足、非法内存访问等仍可能让应用退出。排查不是
  全仓库形式化证明、完整 fuzzing 或渗透测试；没有承诺“不会崩溃”。
- 本轮不删除实际用户媒体、不运行旧 Python sidecar、不操作正式安装的 KDJ。
- RC5 标签已经存在，不能覆盖或倒退版本，因此新的发布候选为 **1.0.0-rc6**。
  跨平台编译、最终安装包大小、updater/Android 签名和 Latest 晋升由现有 CI 门禁决定。
