# KDJ 音频可视化视频：参考图复刻与初版实施计划

日期：2026-09-21。基于用户本次提供的五张截图及当前工作区实际源码。本文替代旧计划中不明确的美术和交互部分，不删除旧实现记录。

## 1. 目标与边界

用户操作：对一首曲目右键 →「生成可视化视频」→ 打开独立右侧面板 → 自动带入歌曲、封面及本地歌词 → 拖动图片调整主体 → 预览 → 导出 MP4。必须至少一张图片，最多两张；一张图片默认同时供左右两栏及唱片使用，两张时左右分别选用。缺封面不能静默导出空画面。

截图显示的是超宽画面中的多层音乐可视化，不是简单的圆环频谱。播放器外部黑边、B 站按钮、平台字幕框不属于模板。五张参考中两张重复；静态截图可确定构图、遮挡及各层的位置变化，但不能证明原视频的精确震动频率、缓动、声音与画面相位。初版复刻视觉结构，以可调、确定性的音频驱动逼近动效，不宣称逐帧逆向还原。

不发布新版本，不改版本号，不提交或推送；保留现有 QQ 音乐修复、Workshop 及其他未提交改动。所有现有共享文件仅作唯一文本匹配的局部接入修改。

## 2. 实际源码基线

已有：`kdj-analysis::visualizer` 流式 FFT、30 Hz 特征时间轴；`kdj-core::audio_visualizer` 场景校验；`compositions/audio_visualizer` 有界帧管道、FFmpeg 导出、硬件编码及软件回退；前端图片裁剪、基础弧线/唱片 Canvas 渲染及测试。

缺少：曲目右键入口、正式编辑面板、完整歌曲信息排版、小频谱/能量线、分层律动、光效、歌词、工程恢复、界面导出任务。旧样片是诊断图案，不是参考图美术。

## 3. 参考画面的分层结构（自底向上）

1. 整幅原色图片铺底，透明图片用浅色衬底，不设黑色频谱底板。
2. 左图：可独立旋转（参考含倒置）、裁剪、镜像、缩放、柔化和淡化；默认同一封面。
3. 右图：主体清晰，采用弧线遮罩；独立图片焦点与独立微位移。
4. 弧形分界：向左内凹的大弧；细亮边、虚线轨道、青绿圆点；遮罩与频谱使用同一几何函数。
5. 弧形主频谱：白色外条与青色内条，双向不等长；音量响应、频带、长度、平滑可调。
6. 左上 Artwork/Album、专辑名；小唱片；可选联名文字。唱片支持隐藏、独立圆盘旋转、正方形封面遮挡旋转圆盘三态。
7. 左中 Track Name、标题、Remix/副标题、Artist Name、艺人及补充信息；长标题自适应，不截断至面板外。
8. 左下小频谱：白柱、青色平滑轮廓及半透明能量线；默认透明、不绘制黑底；柱/线/混合可选。
9. 底部进度、已播放及剩余时间。
10. 少量星点与柔和光斑，以音频强度驱动；不让高亮长期覆盖主体。
11. 可选歌词：底部双语字幕、滚动歌词、唱片环形歌词；全部可关闭。

## 4. 完整工作包（12 组，48 项）

### A. 入口与歌曲隔离（4）
- 单曲右键入口，图片文件禁用。
- 独立右侧面板，固定本次选择的 track id，不随主播放器换歌。
- 自动读取封面/本地歌词，缺素材明确提示；完整本地音频检查。
- 面板关闭、切换工程、导出期间的保护和错误反馈。

### B. 工程模型与恢复（4）
- 版本化工程，视觉场景与输出参数分离。
- 浏览器 IndexedDB 保存工程和最多两个图片 Blob，避免把大图塞进 localStorage。
- 有界撤销/重做与参数重置。
- 工程导入/导出及不携带歌曲/图片凭证的样式预设。

### C. 图片编辑（4）
- 封面默认填充，替换第一张/添加及删除第二张。
- 左右各自选择图片索引、焦点、缩放、旋转、镜像与柔化。
- 预览中选择左/右后拖动画面，滑条精调及复位。
- 尺寸/类型/容量检查及 Object URL 生命周期清理。

### D. 版式与信息（4）
- 参考超宽、16:9、720p、超宽 1080 高画布预设。
- 标题、艺人、专辑、副标题、联名及补充说明可编辑。
- 字体、字号、信息显示与主题强调色。
- 自动适配长文本，进度/计时显示开关。

### E. 唱片（4）
- 隐藏/圆盘/方形遮挡三态。
- 圆形图案、唱片纹理、中心孔、细边与阴影。
- 转速、转向、位置和尺寸。
- 与音频时间绑定，暂停停止、跳转确定性重绘。

### F. 主频谱（4）
- 连续内凹弧形几何及统一遮罩。
- 双向白/青条形、细轨道、分布圆点。
- 灵敏度、长度、颜色、平滑和显隐。
- 频谱与音频特征对应，不使用随机假跳动。

### G. 小频谱（4）
- 原色透明背景，禁止黑色填充曲线。
- 柱状/曲线/混合三态及显隐。
- 平滑青色轮廓和透明能量历史线。
- 与主频谱共享特征，但独立视觉幅度。

### H. 律动（4）
- 低频/RMS/起音驱动的预计算阻尼响应。
- 左图、右图、信息区及唱片分层独立微位移。
- 弧线呼吸与裁剪同步，移动留出超采样边缘。
- 总强度、柔和/关闭、可重复定位；不依赖墙钟或无种子随机数。

### I. 光效（4）
- 轻量青白光斑和音频脉冲。
- 稀疏星点与确定性缓慢飘动。
- 总量/亮度开关与低干扰默认值。
- 明亮背景、暗图、透明立绘均保持可读性。

### J. 歌词（4）
- 自动读取已有本地 LRC，手动导入或粘贴。
- 多时间戳、offset、同时间双语合并及排序。
- 底部/滚动/环形样式、字号、偏移、显隐。
- 无逐字时间时只做整句高亮，不伪称逐字对齐。

### K. 预览与视频导出（4）
- 独立音频预览、播放/暂停、拖动、静音和定位。
- 完整画面共用同一 Canvas 渲染函数；导出按固定帧时间离线绘制，非录屏、不依赖实时播放。
- 原生 FFmpeg H.264/AAC、30/60 fps、硬编/软件选择、有界背压和从第零帧重新绘制的失败回退。
- 进度、取消、素材签名复核、不覆盖已有文件、校验成品后原子提交。

### L. 测试与交付（4）
- 模型/歌词/音频响应/样式及回跳重绘自动测试。
- 后端帧协议顺序、重试代次、取消、参数校验与真实视频测试。
- Chrome 中实际渲染截图及解码 MP4 对照，验证透明底和画面布局。
- 类型检查、相关 Rust 测试、实施报告与样片；单独记录 Windows/Tauri 真机尚未验收项。

## 5. 本次实现方式与性能取舍

保留旧的窄条带 + FFmpeg 静态合成引擎作为底层参考及已有测试对象。新模板有字体、歌词、全画面分层运动和可调光效，初版采用浏览器 Canvas 作为唯一画面源，由受认证的本地 API 把原始 RGBA 帧按需求交给现有原生 FFmpeg 编码器。后端每次仅请求一个带代次/序号的帧；完成写入后才请求下一帧，不缓存整曲帧、不写 PNG 序列、不用逐帧 JSON/Base64。软件回退重新发起第零帧请求，前端按相同工程快照和音频时间确定性重绘。

代价：全帧 RGBA 比旧窄条带带宽大，1080p 每帧约 8.3 MB，30 fps 理论原始通量约 249 MB/s。这是离线导出，不承诺实时速度；实测并如实报告，后续可在保持同一渲染语义的条件下迁移共享纹理/原生图层。30 Hz 音频特征可插值至 60 fps，图片/唱片/文字随输出帧时间连续运动。桌面关闭或前端失联应取消/超时失败，而不是留下无限等待的编码器；初版不承诺关窗后继续导出。

图片由工程持有 Blob，加载完成后锁定本次导出快照；音频固定库内本地文件，开始/结束校验版本。缺失或流媒体占位不可当作完整歌曲导出，不新增绕过平台访问限制的下载逻辑。所有导出控制沿用本地服务 Bearer 验证，不把控制令牌写到工程或图片 URL。

## 6. 面板组织与默认值

预览与传输控制固定在上部；下方分组：歌曲/画布、图片（左/右）、信息、唱片、频谱、律动/光效、歌词、导出。底部导出按钮固定可见。默认参考超宽画布 1920×840 / 30 fps；默认同一封面用于左右，左图柔化倒置、右图清晰；信息/唱片/主频谱/透明小频谱/低强度律动/少量光效开启；歌词默认关闭，用户显式开启后烧录。

音乐分析与素材准备有状态提示。拖动和滑条只改工程，不修改源图片和歌曲标签。导出使用锁定快照，修改按钮在导出期间禁用。关闭面板遇到活动导出须确认取消；刷新/意外失联由后端看门狗收敛。

## 7. 初版验收门槛

- 右键入口真实可进入，不是开发 example 专用功能。
- 第一张图片必需、第二张可选，单图默认封面，左右构图可分别调。
- 画面必须同时具备弧形双向频谱、左信息区、小唱片遮挡、透明小频谱、独立层运动。
- 小频谱背景保留图像原色，不出现原参考不喜欢的黑色填充山形。
- 预览/导出使用同一绘图代码；有声的真实 MP4 能解码，时间和帧数匹配。
- 成功/失败/取消均释放有界帧和任务资源；现有目标不被覆盖。
- 无原视频时，动效精确速度/光斑轨迹列为待用户主观调整，不伪称像素级完整复刻。

实际完成、测试数量、样片位置与剩余项在 `audio-visualizer-reference-implementation.md` 中逐项记录。
