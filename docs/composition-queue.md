# 本地合成队列（历史与恢复）

新的编辑入口已升级为 [VJ 剪辑工坊](vj-workshop.md)。下文记录旧队列行为；未提交的旧组迁移为独立作品，已提交导出的恢复处理保留在工坊菜单的「恢复旧导出」中。

本功能运行在 Rust + Tauri 中，使用本地 FFmpeg / ffprobe，不使用 Python 或云端识别。

## 操作

- 在本地曲库或和声推荐的右键菜单选择「加入合成队列」。命中多选时按当前列表顺序入队。
- 视频和音频分别排队，同一行构成一组。两列各自拖动或使用上移、下移；缺少配对的一侧留空。
- 普通视频不会自动进入音频列。只有把视频的拖动把手拖到另一组视频右侧的空位，才建立视频叠加。
- 完整配对会自动校准，但不自动输出。「开始」仅放行当前完整且可确认的配对。最多同时处理两组；开始后配置锁定，取消后可以重试。
- 顶部设置后的合成图标常驻，有待处理记录时显示红点；面板的固定、关闭和窄屏抽屉复用原有旁路设计。最后一组成功输出并入库后，整组移除、红点消失。空面板保持空白，可用「+」添加曲库所选项。

默认写入新文件并保留完整音频，视频不足处补黑，使用入队时的默认下载目录；可另设合成目录。顶部默认值只作用于之后入队的文件。普通音频和视频叠加入队、配对及校准结果到达时均自动展开操作面板；有未应用修改时暂缓切换，手动收起后普通进度刷新不会重新展开。也可用每组「操作」按钮展开，按区间、画面、输出音频、输出分组配置。视频与音频均可从操作面板装入主轨道试听，主播放条负责暂停、跳转和波形；面板不再维护独立进度条。改变配对会清除旧确认；「重新校准」也可主动清除旧结果。

## 对齐与长度

Offset = 视频匹配位置 − 音频匹配位置。正值延后音频，负值提前音频。解码后的匹配结果包含原容器的音画起始偏差。

普通音轨替换在 ±180 秒内用包络粗定位、短时频谱精定位，并检查重叠片段的前、中、后三个窗口。当音频比视频至少长 10 秒且达到 1.2 倍时，按 short 版本处理：在整首歌内搜索，每 5 秒验证一个 10 秒窗口，优先选择连续共同内容最长的位置，时长相同再比较匹配质量。共同片段需至少 30 秒，偏移漂移不得超过 50 毫秒；允许开头等局部剪辑不同，整段视频只放一次，歌曲其余部分补黑，不循环、不复用其他重复段落。普通完整版本的相似片段歧义、信号不足、不同内容或前后漂移仍要求人工确认，不展示匹配概率。手动选择「放入位置、素材入点、素材出点」，勾选「确认此区间」后应用。也可分别试听主视频和素材，用「取当前」从主轨道捕获对应时间。内部 Offset = 放入位置 − 素材入点，裁剪不会改变素材的原始时间坐标。不能绕过损坏文件、越界或没有时间重叠的错误；无声视频可手动定位画面。

- 保留视频·裁音频：视频时长不变；裁去音频越界部分，空缺处填静音。
- 完整音频·补黑（默认）：取两条轨道区间的并集；片头和片尾缺视频处均补真实黑帧，缺音频处填静音。
- 视频叠加：在整首歌内定位短片段，输出长度保持主视频长度。默认完整保留主视频声音，叠加视频静音。支持居中 50% / 100%、大小、位置、透明度及片段首尾淡入淡出；静音画面预览跟随主轨道实际播放位置，并使用与导出一致的素材区间。声音可选主视频原声、片段替换或叠加混音。

首版普通校准要求至少约 30 秒有效共同内容，短视频叠加至少约 6 秒；超过 30 分钟的文件转为手动校准。不自动变速，不修复中途剪辑导致的多段错位；short 版本依主要共同片段定位，局部剪辑差异仍会保留。自动匹配仅适用于有共同声学内容的录音，不保证不同翻唱或重新编曲能够匹配。

音频配视频可用「播放预览／暂停预览」控制统一试听：完整音频装入主轨道，已对齐的视频跟随实际音频时钟，视频区间外显示黑屏。视频叠加预览使用主视频时钟。预览下方用灰条表示主视频、红条表示音频或叠加视频，显示各自在成品中的起止范围；统一进度指针跟随实际主轨道位置，修改素材区间时同步更新。主播放条仍负责跳转和波形，两个独立素材试听入口保留用于比较。音频输出可选择替换音轨或混合原声，素材与原声音量独立调节（0–200%），素材声音淡入、淡出可分别设置（0–30 秒，短片段限制到片段半长）。混音带峰值限制，避免两路叠加造成削波。预览和素材试听使用原始声音；输出音频设置在合成时生效。

## 硬件编码

需要重编码的 H.264 输出默认自动探测硬件：macOS 使用 VideoToolbox，Windows/Linux 按 NVIDIA NVENC、Intel QSV、AMD AMF 探测。也可指定后端或软件编码。探测使用少量真实编码帧并缓存结果，不能只根据编码器名称推断驱动可用。硬件不可用或编码失败时自动回退软件；取消不重试。直接复制画面流和 WebM 保留原路径。音频识别及合成滤镜仍由 CPU 执行，硬件加速用于视频编码。

## 文件安全与恢复

原视频音轨在替换模式下完全移除；混音模式将原声混入唯一的输出音轨。无补黑时直接复制视频流；叠加或补黑才重编码，保持原分辨率。成品保留原容器与扩展名，按「原名 [合成]」自动编号。

覆盖在原目录内先写临时文件，校验媒体流、时长、尺寸、元数据和章节，再原子替换。原路径同时进行的读写任务互斥，校准和提交时均检查源版本。取消在提交前生效；提交后以持久化回执为准，不会再次覆盖。源文件损坏、权限失败、输出不兼容等错误会保留任务及原文件。无法安全保留的 HDR、高位深、旋转或特殊附加画面信息，在需要重编码时会明确报错；不默默丢弃后覆盖。

覆盖后的曲库 ID、评分、备注、歌单、标签、人工 Cue 保留；补片头时平移 Cue，重试不会重复平移。旧音频、视频转换、封面、波形、节拍及受管歌词缓存失效。数据库中的提交保留记录阻止扫描和目录监听在入库完成前改写原记录。

队列保存在应用数据目录的 `composition-queue.json`。重启不自动执行输出；已提交但未入库的任务恢复为「已输出，入库失败」，重试只补入库。清记录不删除源文件或成品。

## 本地视频同步

本地详情视频、浮窗和合成预览都使用 Rust 实际音频输出时钟。跳转的确认标记在请求真正发送时记录，前一跳转的完成不能满足后一跳转；加载中保留原画面，备用视频接管后不再重复发布旧目标。暂停、换源、循环边界和迟到事件均检查所属会话。

macOS WebKit 保持实际音频速度，避免反复写入播放速度导致画面短停。偏差超过 80 毫秒且持续至少 1 秒时才自动对齐；等待解码恢复后学习落地延迟，下一次对齐补偿该延迟。自动对齐至少间隔 5 秒，未改善时逐次延长至最多 60 秒；用户跳转不受此限制。WebKit 画中画直接使用视频元素，不再复制到未使用的 720p 画布流。

其他引擎沿用有界速率修正：不因 40 毫秒以内的时钟噪声反复调速，每 500 毫秒至多更新一次，幅度限制在音频速度的 ±12%，收敛到 15 毫秒后恢复原速。主视频和叠加视频各自保存修正状态。时钟消息短暂延迟时保持走带，超过 250 毫秒停止基于旧样本纠偏，超过 1.5 秒仍无新样本才暂停画面；真正的加载、换曲和音频缓冲立即停止跟随。视频解码暂时缺帧由媒体自身恢复，不主动反复暂停。过期样本不能确认新跳转已经落地。

播放请求序号同步保存，界面刷新后继续递增，避免 Rust 后端把新点选歌曲误判为旧请求。迟到请求仍保留原序号，不会抢占新歌曲。

## 验证

相关检查：

```sh
npm run typecheck
node --conditions=import scripts/test-composition-ui.mjs
node scripts/test-local-video-device-clock.mjs
node scripts/test-play-intent.mjs
cargo test -p kdj-core composition::tests --lib
cargo test -p kdj-analysis alignment::tests --lib
cargo test -p kdj-server compositions --lib -- --include-ignored
```

最后一项中的媒体验收用例要求本机有 FFmpeg / ffprobe，素材均生成于独立临时目录并自动清理。覆盖了正负及零偏移、不同音量、有损编码的短副歌（误差不超过 50 毫秒）、重复片段/变速拒绝、音轨替换、两端黑帧、叠加首尾淡化、元数据/字幕/章节、取消、并发上限、迟到结果、重启、重名保护、覆盖身份保留及入库失败重试。

macOS Tauri 开发壳使用独立临时曲库验证了右键入队、两视频默认独立待配对、拖动叠加、10.5 秒副歌定位、暂停/播放预览、尺寸应用、输出入库和顶部入口红点消失（旧版入口行为，现已改为常驻）。未操作正式版。Windows 文件占用与不同磁盘权限情形仍需在对应平台验证。

本轮补充验证：核心区间与旧队列默认值 4 项、合成队列/真实媒体/硬件探测回退 22 项、面板交互 4 项、本地视频时钟与跳转顺序 10 项通过。Tauri 开发壳使用独立临时数据目录完成启动与接口验证；未替换已安装正式版。视频同步回归采用可控的时钟和解码事件顺序，具体设备上的实际音画观感仍由播放器实测确认。

持续播放问题追加验证：视频同步回归扩展至 17 项（含三分钟稳定播放和无效纠偏退避），刷新后切歌回归 4 项通过。macOS Tauri 开发壳播放用户的本地合成视频，确认反复改速与画面短停同时出现；改用稳定速度后，采样的稳定播放段音画偏差约 12–24 毫秒，未再改速或自动跳转，浏览器报告丢帧数为 0。用户复测观感已基本正常。临时帧统计代码和收集服务已移除；其他平台尚未实机复测。
