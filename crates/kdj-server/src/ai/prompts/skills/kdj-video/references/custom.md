# VJ 剪辑（用户定制）

用户对素材、结构或做法有自己的要求。用户的话和下面的默认不一样时，以用户的话为准；做工程、保存、播放和报告同 `cut.md`。

## 认得出

- 用户指定了素材、风格或画面：只按用户说的找、用，用户点名要的素材即使和歌无关也照用；
- 用户拖来一首歌和一个视频，或者说「合并」「对上」「把 MV 配上」「音画同步」：见下面「音视频合并」；
- 翻唱、remix 要按新结构重剪，或要更强的效果：见「翻唱和 remix」；
- 一个 DJ 歌单，几首歌接成一个视频：见「DJ 歌单」。

## 音视频合并

### 用户需确认

- 视频常常比歌短（TV size、剪过的 MV），对上之后会有没画面的空档（`kdj_align` 每套方案的 `gaps`）。空档不是错误，是用户要做的决定。
- DJ 接歌时开头和结尾需要画面：哪怕中间全都对上，头尾也可能需要几小节冗余。
- 没有空档就只确认比例和交付；有空档时问：没画面的部分保留黑屏还是填；填多少（开头结尾各留 8 小节冗余 / 全部填满）；
  用什么填（原作动画随机剪辑 / 其他）。KDJ 可视化不是填空档的素材，用户明确要才用。

### 禁止事项

- 对齐靠声音比对，不靠时长（`align.md`）。
- 为了填满而拉无关素材，比黑屏更糟。
- 对不上（`matched` 为 false）就告诉用户，不要硬拼；建议改成 VJ 剪辑（标准）。

### 最简流程

1. 没给视频时，找这首歌的原 MV 或 NCED（`footage.md`，不超过 8 次调用）。B 站的候选先用在线的 ref 对齐，对得上再放进方案；
   YouTube 的在线对不了，方案里写明「下载后才对齐」。
2. `kdj_align`：完整对齐（whole）优先；只有部分对上就用裁切匹配段（sections）。
3. 读 `gaps`：成片里哪几段没画面、各多长。
4. 方案（见下例）。
5. 按选择填空档（剪点落在小节线上），保存、播放，交报告。

## 翻唱和 remix

- 先 `kdj_align`：只是整体变速的 remix（方案的 `speed` 不是 1）常常对得上，照方案铺（`align.md`）；`matched` 为 false 才只能按小节剪，
  要在方案里说明。
- 要不要按新结构重剪、要不要更强的效果，在方案里问（`footage.md`「用户需确认」）。
- 按 remix 重剪：只有对不上的段落按 remix 的小节重剪，drop 处切得更密；更强的效果（闪、切换、频闪）叠在上层。
- 按翻唱重剪：剪点落在翻唱的小节线上。

## DJ 歌单

- 每首对应哪一段通常用户会给；没给就在方案里列出你的对应，让用户确认（`plan.md`）。
- 歌在工程里不是从 0 秒放：对上的片段的 `at` 要加上这首歌片段的 `at` − `in`（`align.md`）。
