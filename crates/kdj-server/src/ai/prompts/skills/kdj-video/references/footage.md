# 确定素材：VJ 素材查找

## 审美规范：用什么画面

用户没指定素材时，用这首歌自己的画面，按这个顺序找：

1. 原作：歌是动画、游戏、剧的 OP/ED/插曲时，原作的无字 OP/ED（NCOP/NCED）、PV、正片片段；
2. 歌的原 MV、官方 PV、Live 映像；
3. 曲库里已有的这首歌的 VJ / MV（`kdj_library_list` 搜歌名）。

KDJ 的可视化不是素材，不在这个顺序里（只在用户明确要可视化时用，`visualizer.md`）。

用户的曲库反映用户的口味：vj 之类的文件夹里放的是什么，就说明用户平常要的是什么。

## 禁止事项

- 用户指定了素材或风格，就只按用户说的找。
- 和这首歌无关的素材一律不用：抽象循环、粒子、隧道、通用背景、按歌词字面意思找来的画面。用户点名要的除外。
- 有几种画面（动画 MV / 真人 MV / PV / Live）时不要自己混用风格。
- 探索时不下载；搜索和查资料不超过 8 次调用（给候选截帧的 `kdj_peek`、给每个候选做的那一次 `kdj_align` 不算在内）。
- `kdj_search` 只用来找素材视频，不搜这首歌本身（`song.md`）。

## 用户需确认（放进方案）

- **同一首歌有几种画面**（动画 MV 和真人 MV、PV 和 Live、TV 版和完整版）：它们是不同的作品，风格不同。把找到的几种都列出来，
  说明各是什么，推荐一种（参考用户的话和用户曲库里的口味）。
- **翻唱**（歌ってみた、cover）：原曲的 MV 属于原唱，画面里是别人，编曲和速度也常常不同，声音常常对不上
  （先 `kdj_align` 试，`matched` 为 false 才算对不上）。问用户：用原曲 MV 按翻唱的结构重新剪、用原作（动画等）的画面、
  还是用翻唱自己的视频（有的话）。
- **remix / bootleg / 加速版**：很多 remix 用的是原曲人声、只是整体变了速（比如 160 BPM 放慢到 145），原版画面照样对得上：
  **先 `kdj_align`**，它会给出 `speed`；只有对不上的段落才按 remix 的小节重剪。问用户：只用原版画面、按 remix 的小节和 drop
  重新剪（drop 处切得更密），还是需要更强的效果（闪、切换、频闪）来配 remix 的风格。

## 最简流程

1. 用 `song.md` 查到的作品名，`kdj_search` 找候选；看曲库里有没有这首歌的 VJ / MV。
2. 推荐的视频素材都用 `kdj_peek` 看过（在线 B 站和曲库视频不用下载就能看；YouTube 下载前看不到，只能看封面）。
3. 每个含这首歌声音的候选 `kdj_align` 一次（`align.md`）。
4. 记下每个候选的时长、有没有字幕、整首还是 short、是哪一种画面、对齐的结果。

## 出错时

- 这首歌在网上确实找不到能用的画面：告诉用户找了哪些、缺什么，问用户怎么办；不要自己改做可视化。
- 下载失败、下到的和方案说的不一样、下载后对不上：先 `ask_user`（`confirm.md`），不要换别的素材硬做。

## 交付 / 进入下一阶段

- 候选用 `<media>` 和 `<shot>` 放进方案（`confirm.md`）。
- 用户确认后用 `kdj_download`（`as: "video"`）下到方案里定的文件夹，之后用下载得到的本地路径，并用本地文件再对齐一次（`align.md`）。
  再进入 `cut.md` 或 `custom.md`。
