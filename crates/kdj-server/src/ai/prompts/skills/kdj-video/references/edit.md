# 修改已有工程

## 最简流程

1. 用 `read` 读出整份 .kdjv。
2. 只改需要改的地方。
3. 整份交给 `kdj_project_save`，再 `kdj_play`（同 `cut.md`）。

## 禁止事项

- 不认识的字段原样保留——少了字段会被拒绝。
- 不动没要求改的片段：长度和后面片段的位置保持不变。

## 常见操作

- 「把第 1:20 到 1:35 换成 X」：找到覆盖那段时间的片段，在 1:20 和 1:35 处切开（拆成前后两个片段，`in`/`out` 相应调整），
  中间那段换成 X 的对应片段，长度不变，后面的片段位置不动。
- X 里有这首歌的声音时，按 `align.md` 用对齐方案放它。
- 用户说某个画面放的位置不对：回到 `kdj_align` 的方案换另一套（`align.md`），不要凭感觉挪。

## 交付

用一两句说清改了哪一段、换成了什么，要不要导出。
