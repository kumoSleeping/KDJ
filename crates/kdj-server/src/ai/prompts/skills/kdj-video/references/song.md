# 确定素材：歌曲查询

查清这首歌是什么、出自哪里、段落在哪。后面找素材和剪辑都靠它。

## 常见操作

- 这首歌已经在曲库里（用户拖进来的、`kdj_library_list` 找到的）时，不要用 `kdj_search` 再搜它：搜索页会白白显示一次，
  网易云也查不出它出自哪部作品。
- 歌名、歌手、专辑、出自哪部作品：`kdj_library_get`；还不清楚就用网页搜索。名字不确定（新番、简称、错字、中文译名）也先用网页搜索查准。
- 段落和剪点：`kdj_library_get` 的小节线（`grid.downbeats`）、`bpm` 和 `segments`；用户标的时间优先。
- 认出翻唱和 remix：标题或歌手和原曲不同（歌ってみた、cover）的是翻唱；remix / bootleg / 加速版的结构和原曲不同
  （更长的前奏、build、drop），BPM 往往也不同。它们怎么找画面见 `footage.md`，怎么剪见 `custom.md`。

## 禁止事项

- 不写脚本分析音频（切片段、算能量、算相关、变调重对）：歌里有什么，只问 `kdj_align` 和 `kdj_library_get`。

## 出错时

- 没有小节线（`grid.downbeats` 为空）：用 `bpm` 和 `segments` 推段落和剪点，在方案里写明是推的、请用户改。

## 最简流程

1. `kdj_library_get` 读这首歌：出自哪里、段落、小节线。
2. 出自哪里还不清楚时用网页搜索。

## 交付 / 进入下一阶段

记下：出自哪部作品（找素材用）、整首多长、段落和副歌在哪、是不是翻唱或 remix。要视频素材的进入 `footage.md`；可视化直接交方案（`confirm.md`）。
