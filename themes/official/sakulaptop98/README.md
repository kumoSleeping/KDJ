# Sakura98

版本 **6.1.9**，官方按需下载主题，固定浅色。沿用内部 ID 和文件夹名 `sakulaptop98`，保留已有用户的主题选择。

## 安装

在 KDJ 设置的官方主题中下载 **Sakura98**，安装成功后自动切换。安装包不内置此主题。
也可以将完整 `sakulaptop98` 文件夹放入数据目录的 `themes/`，在设置中选择 **Sakura98**。

macOS 默认位置：`~/Library/Application Support/com.kdj.app/data/themes/sakulaptop98/`。

主样式相对导入 `player.css`、`surfaces.css`、`video.css`、`adaptations.css`，分发时请使用完整文件夹或 ZIP。旧的 Sakura 系列目录和压缩包已由此主题取代；其他主题不受影响。

## 外观

- 保留原有立体侧栏、真实文件夹层级、播放器布局和字号缩放，不重置列顺序或列宽。
- 本地文件、网易云等在线歌单和搜索结果的所有列统一使用暖浅粉底色，包括序号、标题、属性列与空白区域；不按列交替，不添加网格线或逐行条纹。输入框、计数与控制读数同样使用浅粉底板。
- 正在播放、下一首与底部波形使用粉色底板。波形以柔和鲜樱粉为主，低频带柔玫红、高频带低饱和暖黄；保留原有幅度、频段变化与底板对比度校准。
- 面板使用较深标题和较浅内容区。调性分析改为 Win98 凹槽表格，保留 24 个 Camelot 调性和点击筛选；当前调性使用深红文字。
- 列表当前选中、详情定位和播放曲目的标题加强红色与字重，不添加选中背景；键盘焦点保持独立。
- 主题选择器使用 Win98 下拉框外观，不再显示系统白色圆角控件。
- 共享视频小窗仅标题头与关闭键使用 98 风格；不再添加立体外框、播放控件底板、进度槽或装饰缩放角。鼠标悬停或键盘聚焦时显示原有轻量控制，平时隐藏；触屏保留可操作的轻量控制。不染色视频画面。
- 桌面歌词保留透明背景、用户自定义颜色、字号、描边和逐字填充。

## 配套应用改动

以下改进需要使用包含相应代码的开发版或后续版本，单独导入 ZIP 不会更新旧版应用：

- 桌面歌词从空闲切换到播放时的 React Hook 顺序修复。
- 自定义歌词主色时，副行“跟随”不再被主题覆盖。
- 调号轮的主题样式标记，以及总览波形底色的独立对比度校准令牌。
